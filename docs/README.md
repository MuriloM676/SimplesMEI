# SimplesMEI

SimplesMEI é uma plataforma web que automatiza a burocracia para MEIs, autônomos e pequenos empregadores no Brasil. O objetivo é simplificar tarefas como emissão de notas fiscais eletrônicas (NFSe), cálculo e pagamento de DAS, suporte via chatbot e exibição de informações em um dashboard intuitivo.

## Funcionalidades Principais
1. **Emissão de NFSe**: Integração com a API de São Paulo, exportação em PDF e controle de limite mensal.
2. **Cálculo e Pagamento de DAS**: Cálculo automático, geração de boleto ou Pix e alertas de vencimento.
3. **Chatbot de Suporte**: Respostas automáticas para dúvidas frequentes e escalação para suporte humano.
4. **Dashboard do Usuário**: Exibição de faturamento mensal, NFSe emitidas, status do DAS e alertas.

## Tecnologias Utilizadas
- **Frontend**: React.js
- **Backend**: Node.js com Express
- **Banco de Dados**: MongoDB
- **Chatbot**: Dialogflow
- **Deploy**: Docker
